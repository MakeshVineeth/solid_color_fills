# Architecture Specifications (C4 Model)

This directory contains the C4 model diagrams for Solid Color Fills across Context, Container, Component, and Deployment levels.

## Diagrams
1. **Context Level**: Defines the system boundary, user interactions, and external operating system services (Android Wallpaper Manager, Gallery, Play Store).
2. **Container Level**: Describes the Flutter presentation client, local storage, platform channels, and canvas rendering engine.
3. **Component Level**: Breaks down the `wallpaper`, `collections`, `color_picker`, and `feed` feature modules.
4. **Deployment Level**: Illustrates the production deployment topology across Android devices (phones, tablets, foldables, and TV/desktop).
